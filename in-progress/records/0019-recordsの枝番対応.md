# 設計判断ログ

## 0019: records の枝番対応

- 日付: 2026-05-09
- 状態: 採用
- ドキュメント: 未着手
- 実装: 未着手

### 背景

records が増えるにつれ、ひとつの record から派生する検討事項（例：0017 の検証結果 V1・V2 が独立した record になる場合）が生まれる。現状の `XXXX-タイトル.md` という平坦な連番では、親 record との関係が失われ文脈が追いにくくなる。

### 判断

親 record の派生として記録する場合、以下の枝番形式を採用する：

```
{親番号}-{枝番}-{タイトル}.md
```

**採番ルール：**

| パターン | 例 | 意味 |
|---------|---|------|
| `0017-0-タイトル.md` | 枝番の最初 | 0017 から派生した最初の枝 |
| `0017-1-タイトル.md` | 枝番の2番目 | 0017 から派生した2番目の枝 |
| `0017-0-1-タイトル.md` | 枝の階層化 | 0017-0 からさらに派生した場合 |

- 枝番は 0 始まり
- 必要に応じて `{親}-{枝}-{サブ枝}` と階層を深められる
- 独立した新テーマは従来通り連番（0020, 0021…）で採番する

### 理由

- 親 record との関係がファイル名から読み取れる
- 平坦な連番を壊さずに派生記録を挿入できる
- 必要な深さだけ階層化できる（過剰に深くしない）

### 却下した選択肢

| 案 | 却下理由 |
|---|---|
| 親 record 内にセクション追記 | 1ファイルが肥大化し、critique/propose の対象として扱いにくい |
| `0017a`, `0017b` 形式 | 連番との区別が視覚的に分かりにくい。ソート順が崩れる |
| 完全な独立連番で管理 | 親子関係がファイル名から消え、文脈が失われる |

### 影響

- `records-add` スキルが枝番形式を採番できるよう修正が必要
- 既存 records は変更不要（遡及適用しない）

### docs 記載方針

- `packages/template/in-progress/records/` 配下のサンプル record のファイル名規約に枝番形式を追記する

### 実装方針

1. **`records-add` スキルの修正**
   - 枝番指定オプションを追加（例：`/records-add --parent 0017 タイトル` で `0017-0-タイトル.md` を採番）
   - 親番号が指定された場合、既存の枝番を確認して次の空き枝番を採番する
